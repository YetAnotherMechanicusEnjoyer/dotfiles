# Absolute Rizz dotfiles

on skibidi those are my dotfiles

# Installation

simply run the following command:

```bash
bash <(curl -sSfL dotfiles.frezzydy.com)
```

> [!NOTE]
> __OS__: `Arch Linux (btw)`
>
> __Desktop Environment__: `Hyprland or i3`
>
> __Desktop Manager__: `sddm + Davi-S' MineSDDM Theme`
>
> __Bootloader__: `Grub + Lxtharia's Minegrub Theme`
>
> __Term__: `eDEX-UI & Ghostty (+ tmux)`
>
> __Shell__: `zsh`
>
> __Prompt__: `starship`
>
> __Font__: `JetBrainsMono Nerd Font`
>
> __Theme__: `Eldritch`
>
> __Editor__: `Neovim`
>
> __Misc__: `Some usefull shell scripts (e.g.: full system & dotfiles update)`

> [!TIP]
> With the help of [ML4W's dotfiles](https://github.com/mylinuxforwork/dotfiles) & [end-4's dots-hyprland](https://github.com/end-4/dots-hyprland.git) for Hyprland base config.
